Overview

MGFView.js is a lightweight JavaScript library for parsing, viewing, and analyzing Mascot Generic Format (MGF) mass spectrometry files directly in the browser. It requires no build tools, no external dependencies, and works with vanilla JavaScript in modern web browsers.

Key Features

MGF Parsing

Robust parsing engine with comprehensive error handling, whitespace normalization, and vendor-specific field support.

Interactive Visualization

Canvas-based spectrum plots with zoom, pan, peak selection, and 4x resolution scaling for high-quality exports.

Search & Filter

Multi-criteria search including title, precursor mass, charge state, retention time, and custom metadata fields.

Statistical Analysis

Automated calculation of distributions, histograms, and summary statistics for peak counts, masses, and charges.

Multi-Format Export

Export to JSON, CSV, MGF, PNG (4x), SVG, and interactive HTML with full metadata preservation.

Plugin System

Extensible architecture with lifecycle hooks for custom processing, validation, and export formats.

Input Formats Supported

  • Raw MGF strings
  • File uploads (File/Blob objects)
  • Remote URLs (HTTP/HTTPS)
  • Pre-parsed JavaScript objects
  • Arrays of spectrum objects

Output Formats

  • JSON - Complete spectrum data with metadata
  • CSV - Tabular format with customizable columns
  • MGF - Reconstruct original Mascot format
  • PNG - High-resolution plot images (4x scaling)
  • SVG - Scalable vector graphics with embedded data

Architecture

MGFView.js follows a modular architecture with loosely-coupled components. Each module is self-contained and can be used independently or as part of the complete library.

Core Components

Module File Purpose
MGFParser parser.js Parses MGF files into structured spectrum objects
MGFViewer viewer.js High-level API for loading and displaying spectra
Spectrum spectrum.js Data model representing a single spectrum
SpectrumPlot plot.js Canvas-based visualization with interactive controls
SearchFilter search.js Multi-criteria search and filtering engine
StatisticsPanel stats.js Statistical analysis and distribution generation
ExportManager export.js Multi-format export functionality
Plugin System plugin.js Extensibility framework with lifecycle hooks
Utilities utils.js Common helper functions and validators
MGFView mgfview.js Library entry point and factory methods

Data Flow

The typical data flow follows this pattern:

  1. Input - File, URL, or string passed to MGFParser
  2. Parsing - MGFParser extracts spectra and metadata
  3. Storage - Spectra stored as Spectrum objects
  4. Processing - Optional filtering, searching, or statistical analysis
  5. Visualization - SpectrumPlot renders selected spectrum
  6. Export - ExportManager converts to desired format

Installation

Quick Start (Recommended)

Include the CSS and main library file - dependencies are auto-loaded:

<!DOCTYPE html>
<html>
<head>
    <link rel="stylesheet" href="path/to/css/mgfview.css">
    <script src="path/to/src/mgfview.js"></script>
    
</head>
<body>
    <div id="viewer"></div>
    <script>
        const viewer = new MGFViewer('#viewer');
    </script>
</body>
</html>

Advanced: Manual Component Loading

For fine-grained control, load components individually in order:

<script src="path/to/src/utils.js"></script>
<script src="path/to/src/parser.js"></script>
<script src="path/to/src/spectrum.js"></script>
<script src="path/to/src/plot.js"></script>
<script src="path/to/src/viewer.js"></script>
<script src="path/to/src/search.js"></script>
<script src="path/to/src/stats.js"></script>
<script src="path/to/src/export.js"></script>
<script src="path/to/src/plugin.js"></script>
<script src="path/to/src/mgfview.js"></script>

Usage: Each component exports to the global window object and can be used independently:

const parser = new MGFParser();
const search = new SearchFilter();
const stats = new StatisticsPanel();
const exporter = new ExportManager();
Note: The library requires modern browser features including ES6+ (classes, arrow functions, async/await), Canvas API, and File API. Supported in Chrome 60+, Firefox 60+, Safari 12+, Edge 79+.

API Reference

MGFParser

Core parsing engine for MGF file format.

constructor()
Creates a new parser instance. No parameters required.
async load(input)
Auto-detects input type and loads MGF data.
Parameters:
input - String (URL or MGF content), File/Blob object, or pre-parsed Object/Array
Returns:
Promise resolving to {count, spectra, metadata}
loadString(mgfString)
Parses MGF format string synchronously.
Parameters:
mgfString - Raw MGF file content
Returns:
{count, spectra, metadata}
async loadUrl(url)
Fetches and parses MGF file from URL.
Parameters:
url - HTTP/HTTPS URL or relative path
Returns:
Promise resolving to parsed result
async loadBlob(blob)
Reads and parses File or Blob object.
Parameters:
blob - File or Blob object
Returns:
Promise resolving to parsed result
getSpectra()
Returns array of all parsed spectra.
Returns:
Array of Spectrum objects
getSpectrum(index)
Returns single spectrum by index.
Parameters:
index - Zero-based spectrum index
Returns:
Spectrum object
getSpectrumCount()
Returns total number of spectra.
Returns:
Integer count

SpectrumPlot

Canvas-based spectrum visualization with interactive controls.

constructor(container, options)
Creates spectrum plot in specified container.
Parameters:
container - DOM element or CSS selector string
options - Configuration object (colors, dimensions, margins)
setSpectrum(spectrum)
Loads and displays a spectrum.
Parameters:
spectrum - Spectrum object with metadata and peaks
draw()
Redraws the plot canvas. Called automatically after changes.
exportPNG(scale)
Exports current plot as PNG image.
Parameters:
scale - Resolution multiplier (default: 4)
Returns:
Base64 PNG data URL
exportSVG()
Exports current plot as SVG.
Returns:
SVG markup string

SearchFilter

Advanced search and filtering for mass spectrometry data.

constructor(options)
Creates filter instance with configuration.
Parameters:
options - {caseSensitive, fuzzyMatch}
filter(spectra, criteria)
Apply multiple filter criteria simultaneously.
Parameters:
spectra - Array of spectra to filter
criteria - Object with filter conditions (title, mass, charge, rt, metadata)
Returns:
{matched, excluded, metadata}
searchByTitle(spectra, query)
Search spectra by title substring.
Parameters:
query - Search string
Returns:
Array of matching spectra
filterByCharge(spectra, charges)
Filter by charge state.
Parameters:
charges - Array of allowed charge values
Returns:
Filtered spectra array

StatisticsPanel

Statistical analysis and distribution visualization.

constructor(options)
Creates statistics panel.
Parameters:
options - {histogramBins, colors}
analyze(spectra)
Analyzes array of spectra and generates statistics.
Parameters:
spectra - Array of spectrum objects
getStatistics()
Returns computed statistics object.
Returns:
Statistics summary with distributions, min/max/mean values

ExportManager

Multi-format data export functionality.

exportJSON(spectra, pretty)
Exports spectra as JSON string.
Parameters:
spectra - Array of spectra
pretty - Format with indentation (default: true)
Returns:
JSON string
exportCSV(spectra, options)
Exports spectra as CSV.
Parameters:
options - {includePeaks, includeMetadata, delimiter}
Returns:
CSV formatted string
exportMGF(spectra)
Reconstructs MGF format from parsed spectra.

MGF formatted string
downloadJSON(spectra, filename)
Triggers browser download of JSON file.
downloadCSV(spectra, filename)
Triggers browser download of CSV file.
downloadMGF(spectra, filename)

Usage Examples

Basic File Loading

// Create parser instance
const parser = new MGFParser();

// Load from file input
const fileInput = document.getElementById('file-input');
fileInput.addEventListener('change', async (e) => {
    const file = e.target.files[0];
    const result = await parser.loadBlob(file);
    console.log(`Loaded ${result.count} spectra`);
});

// Load from URL
await parser.loadUrl('path/to/spectra.mgf');

// Load from string
const mgfString = `BEGIN IONS
TITLE=Spectrum 1
CHARGE=2+
PEPMASS=445.2
100.5 1234.5
200.7 5678.9
END IONS`;
parser.loadString(mgfString);

Visualization

// Create plot container
const plot = new SpectrumPlot('#plot-container', {
    width: 800,
    height: 400,
    colors: {
        peak: '#555',
        selected: '#000'
    }
});

// Display first spectrum
const spectrum = parser.getSpectrum(0);
plot.setSpectrum(spectrum);

// Export as image
const pngData = plot.exportPNG(4); // 4x resolution
const svgMarkup = plot.exportSVG();

Search and Filter

const search = new SearchFilter({
    caseSensitive: false,
    fuzzyMatch: false
});

const spectra = parser.getSpectra();

// Search by title
const results = search.searchByTitle(spectra, 'peptide');

// Complex filtering
const filtered = search.filter(spectra, {
    title: 'experiment',
    chargeLow: 2,
    chargeHigh: 3,
    massLow: 400,
    massHigh: 1500,
    rtMin: 10.0,
    rtMax: 30.0
});

console.log(`Matched: ${filtered.matched.length}`);
console.log(`Excluded: ${filtered.excluded.length}`);

Statistical Analysis

const stats = new StatisticsPanel({
    histogramBins: 20
});

// Analyze all spectra
stats.analyze(parser.getSpectra());

// Get statistics object
const statistics = stats.getStatistics();
console.log(statistics);

// Export statistics
const jsonStats = stats.exportJSON();
const csvStats = stats.exportCSV();

Data Export

const exporter = new ExportManager();
const spectra = parser.getSpectra();

// Export to different formats
const json = exporter.exportJSON(spectra);
const csv = exporter.exportCSV(spectra);
const mgf = exporter.exportMGF(spectra);

// Trigger downloads
exporter.downloadJSON(spectra, 'data.json');
exporter.downloadCSV(spectra, 'data.csv');
exporter.downloadMGF(spectra, 'reconstructed.mgf');

Complete Workflow

// Initialize components
const parser = new MGFParser();
const search = new SearchFilter();
const stats = new StatisticsPanel();
const exporter = new ExportManager();
const plot = new SpectrumPlot('#plot');

// Load file
await parser.loadUrl('spectra.mgf');

// Filter spectra
const filtered = search.filter(parser.getSpectra(), {
    chargeLow: 2,
    chargeLow: 4,
    massLow: 500,
    massHigh: 2000
});

// Analyze filtered results
stats.analyze(filtered.matched.map(r => r.spectrum));

// Display first result
if (filtered.matched.length > 0) {
    plot.setSpectrum(filtered.matched[0].spectrum);
}

// Export filtered data
exporter.downloadCSV(
    filtered.matched.map(r => r.spectrum),
    'filtered_spectra.csv'
);

Processing Workflow

1. File Loading

MGFParser accepts multiple input types and automatically detects the format:

  • String - Checks if URL pattern, fetches if true, otherwise parses as MGF content
  • File/Blob - Reads using FileReader API, then parses content
  • Object - Accepts pre-parsed spectrum objects with {metadata, peaks} structure
  • Array - Accepts array of pre-parsed spectrum objects

2. Parsing Process

The parser follows these steps:

  1. Split input into individual spectrum blocks (BEGIN IONS...END IONS)
  2. Extract global file metadata (before first BEGIN IONS)
  3. For each spectrum:
    • Parse metadata key-value pairs (TITLE, CHARGE, PEPMASS, etc.)
    • Parse peak list (m/z intensity pairs)
    • Validate data structure
    • Create Spectrum object
  4. Store in internal array

3. Data Structures

Internal representation of a spectrum:

{
    metadata: {
        TITLE: "Spectrum name",
        CHARGE: "2+",
        PEPMASS: "445.234",
        RTINSECONDS: "1234.5",
        ...customFields
    },
    peaks: [
        {mz: 100.5, intensity: 1234.5},
        {mz: 200.7, intensity: 5678.9},
        ...
    ]
}

4. Visualization Process

SpectrumPlot rendering pipeline:

  1. Calculate canvas dimensions with devicePixelRatio scaling
  2. Determine plot area (subtract margins for axes)
  3. Calculate data ranges (min/max m/z and intensity)
  4. Draw grid and axes with labels
  5. Transform peak coordinates to canvas space
  6. Render peaks as vertical lines with optional selection highlights
  7. Handle mouse events for hover and selection

5. Search Algorithm

SearchFilter applies filters in sequence:

  1. Start with all spectra
  2. Apply title filter (substring match or regex)
  3. Apply charge filter (exact match or range)
  4. Apply precursor mass filter (range with tolerance)
  5. Apply retention time filter (min/max range)
  6. Apply custom metadata filters
  7. Return matched and excluded arrays with metadata

6. Statistical Calculations

StatisticsPanel computes:

  • Distributions - Binned histograms for peaks, masses, charges, retention times
  • Summary Stats - Min, max, mean, median, standard deviation
  • Counts - Total spectra, total peaks, peaks per spectrum
  • Quality Metrics - Coverage, intensity ranges

7. Export Pipeline

ExportManager conversion process:

  1. JSON - Serialize spectrum objects directly
  2. CSV - Flatten metadata to columns, optionally include peaks as rows
  3. MGF - Reconstruct text format with BEGIN/END IONS blocks
  4. PNG - Render to temporary canvas at high resolution, export as base64
  5. SVG - Generate XML markup with embedded spectrum data
